# Changesets

Run `vp run changeset` when changing a published package. Choose a bump type and
write a short description for the changelog, then commit the generated Markdown
file with the implementation.

The three `@relay-dx` packages release together. The private workspace and
kitchen-sink example are never published.

See [the release guide](../docs/releases.md) for version PRs, native build
artifacts, and npm trusted publisher setup.
